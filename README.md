# 🚀 AI Hiring Intelligence Platform

An advanced **AI-powered resume screening and hiring intelligence platform** built using **FastAPI + Streamlit**.

This project helps recruiters and hiring teams:
- parse resumes automatically
- generate ATS scores
- compare resume fit with job descriptions
- visualize skill strength
- provide recruiter-ready hiring insights
- download hiring reports

---

## ✨ Features
- 📄 Resume PDF parsing
- 🎯 ATS scoring engine
- 🧠 JD matching logic
- 📊 Skill strength visualization
- 💡 Recruiter insights
- 📥 Hiring report download
- 🌙 Premium dark dashboard UI
- ⚡ FastAPI backend API
- 🎨 Streamlit interactive frontend

---

## 🛠 Tech Stack
- **Frontend:** Streamlit
- **Backend:** FastAPI
- **Visualization:** Plotly
- **PDF Parsing:** pdfplumber
- **Language:** Python
- **Data Handling:** Pandas
- **Deployment Ready:** Streamlit Cloud / Render
